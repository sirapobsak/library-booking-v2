# เครื่องเฝ้าเสียงประจำโต๊ะ (ESP32 + INMP441 + OLED + LED 3 ดวง)

MicroPython สำหรับ **Thonny** — โค้ดอยู่ที่ [`noise_meter/main.py`](noise_meter/main.py)

## ใช้ ESP32 2 ตัว ทำงานร่วมกัน

ESP32 ธรรมดา (ไม่มี RAM เสริม) หน่วยความจำไม่พอให้ไมค์ + จอ + การต่อเว็บแบบ HTTPS อยู่บนตัวเดียวกัน จึงแบ่งงานเป็น 2 บอร์ด

| | บอร์ดที่ 1 — ที่โต๊ะ | บอร์ดที่ 2 — ต่อเว็บ |
|---|---|---|
| โค้ด | [`noise_meter/main.py`](noise_meter/main.py) | [`link_board/main.py`](link_board/main.py) |
| ต่อกับ | ไมค์ INMP441, จอ OLED, LED 3 ดวง (สายเดิมทั้งหมด) | ไม่มีอุปกรณ์อื่น |
| ทำอะไร | ลดเสียงรบกวน จับเสียงพูด นับ 5 วินาที จอตา/นับถอยหลัง ไฟเตือน — **ไม่ต่อ WiFi** | ต่อ WiFi ถามการจองจากเว็บทุก 30 วิ ส่งหักคะแนน (ส่งไม่สำเร็จเก็บคิวลองใหม่เอง) |
| ตั้งค่าในส่วนที่ 1 | ไม่ต้องใส่อะไร | ชื่อ/รหัส WiFi + 5 บรรทัดของโต๊ะจากหน้าผู้ดูแล |

**สายระหว่าง 2 บอร์ด (3 เส้น)** — บอร์ดที่ 1 ใช้ขาฝั่งขวาเหมือนเดิม

| บอร์ดที่ 1 | | บอร์ดที่ 2 |
|---|---|---|
| D5 (ส่ง) | → | D16 (รับ) |
| D15 (รับ) | ← | D17 (ส่ง) |
| GND | — | GND |

ไฟเลี้ยง: เสียบ USB ทั้ง 2 บอร์ด หรือต่อ **VIN ↔ VIN** เพิ่มอีกเส้น (ใช้ USB เส้นเดียวเลี้ยง 2 บอร์ดได้)
ไฟสีฟ้าบนบอร์ดที่ 2: กะพริบ = กำลังต่อ WiFi/เว็บ, ติดค้าง = คุยกับเว็บได้แล้ว
จอบอร์ดที่ 1 มุมขวาบนบอกปัญหา: `NO LINK` (ไม่ได้ยินบอร์ด 2 — เช็คสาย 3 เส้น), `NO WIFI`, `BAD KEY`, `WEB ERR`, `LINKING` (กำลังถามเว็บ) — รายละเอียดใน Shell

## การทำงาน

1. ทุก 30 วินาที บอร์ดถามเว็บว่า "ตอนนี้โต๊ะนี้มีคนจองอยู่ไหม จองถึงกี่โมง"
2. **เฝ้าเสียงเฉพาะช่วงเวลาที่มีการจอง** — ดังเกิน **65 dB** สะสมครบ **5 วินาที** = เสียงดัง 1 ครั้ง
   - ระหว่างจับเวลา ถ้าเงียบแป๊บเดียว เวลาที่ดังไปแล้วยังนับต่อ
   - แต่ถ้า**เงียบติดกันเกิน 10 วินาที** = ไม่นับ ไม่หัก ล้างเวลาทิ้งเริ่มใหม่
3. จอ: มีเสียงพูดดัง → **2 วินาทีแรกตาโกรธ** (คิ้วขมวด) → **3 วินาทีสุดท้าย**นับถอยหลัง **3 → 2 → 1** ตัวใหญ่
4. ไฟเตือน (ติดทีละดวง) — ขึ้นไฟเตือนแล้ว **เวลาที่เงียบบนจอกลับเป็น 0** เริ่มจับใหม่

   | เสียงดังครั้งที่ | ไฟ | เว็บ |
   |---|---|---|
   | 1 | 🟢 เขียว | — |
   | 2 | 🟡 เหลือง | — |
   | 3 | 🔴 แดง | หักคะแนนความประพฤติ |
   | 4, 5, … | 🔴 แดงค้าง | หักทุกครั้ง |

5. **หมดเวลาจอง** → ไฟดับ นับใหม่จาก 0 สำหรับการจองรอบถัดไป
6. หักจากทุกคนในการจองโต๊ะนั้น (คนจอง + เพื่อนที่เข้าร่วมด้วย QR) — **หักเท่าไรเป็นไปตามระบบคะแนนบนเว็บ**
   (ตอนนี้: ครั้งแรกของวัน −5 แล้วแรงขึ้นทีละ 5 สูงสุด −20 ต่อครั้ง รวมไม่เกิน −40 ต่อวัน ตั้งได้ในหน้าผู้ดูแล) บอร์ดแค่แสดงตามที่เว็บบอก

## ต่อสาย (ขาฝั่งขวาของบอร์ดทั้งหมด)

ทำรางไฟบน breadboard ก่อน: ขา **3V3 → ราง +** และขา **GND → ราง −**
(⚠️ ราง + ต้องเป็น 3.3V เท่านั้น ห้ามต่อ VIN/5V — ไมค์ INMP441 รับได้สูงสุด 3.6V)

| อุปกรณ์ | ขาอุปกรณ์ | ต่อไปที่ |
|---|---|---|
| ไมค์ INMP441 | VDD | ราง + |
| | GND | ราง − |
| | L/R | ราง − (ห้ามปล่อยลอย) |
| | SD | D23 |
| | WS | D19 |
| | SCK | D18 |
| จอ OLED | VDD | ราง + |
| | GND | ราง − |
| | SDA | D21 |
| | SCK | D22 |
| LED เขียว | ขายาว (+) | ตัวต้านทาน 220Ω → D17 |
| LED เหลือง | ขายาว (+) | ตัวต้านทาน 220Ω → D16 |
| LED แดง | ขายาว (+) | ตัวต้านทาน 220Ω → D4 |
| LED ทุกดวง | ขาสั้น (−) | ราง − |

ไม่ใช้: TX0 / RX0 (ใช้คุยกับคอมผ่าน USB), D2 / D5 / D15 (มีผลตอนบอร์ดเปิดเครื่อง)
ถ้าเป็นโมดูลไฟจราจร (ขา R Y G GND) ไม่ต้องใส่ตัวต้านทาน: G→D17, Y→D16, R→D4, GND→ราง −

## ติดตั้งใน Thonny

1. เสียบบอร์ด → Thonny มุมขวาล่างเลือก **MicroPython (ESP32)** (เฟิร์มแวร์ MicroPython 1.19 ขึ้นไป)
2. **Tools → Manage packages** → ค้น `ssd1306` → Install (ไลบรารีจอ OLED — ถ้าบอร์ดมีอยู่แล้วข้ามได้)
3. **บอร์ดที่ 1**: เปิด `noise_meter/main.py` (ไม่ต้องแก้อะไร) / **บอร์ดที่ 2**: เปิด `link_board/main.py` → แก้ **ส่วนที่ 1** ใส่ชื่อ/รหัส WiFi + บรรทัดของโต๊ะจากเว็บ (ดูหัวข้อถัดไป)
   ทำทีละบอร์ด: เสียบบอร์ดไหน Thonny ก็คุยกับบอร์ดนั้น (มุมขวาล่างเลือกพอร์ตได้)
4. **File → Save as… → MicroPython device** → ตั้งชื่อ `main.py` (บอร์ดรันเองทุกครั้งที่เสียบไฟ)
5. กด **Stop/Restart** (Ctrl+F2) — **3 วินาทีแรกขอให้เงียบ** (จอเป็นตาหลับ + `CALIBRATING` บอร์ดกำลังฟังเสียงพื้นหลัง) จากนั้น Shell ขึ้นค่า dB ทุก 1 วินาที

บนบอร์ดจะมี 2 ไฟล์: `main.py` และ `lib/ssd1306.py`

> ⚠️ `main.py` ที่ใส่คีย์จริงแล้ว **ห้ามอัปขึ้น GitHub** (repo นี้เป็น public) — เก็บไฟล์นั้นไว้นอกโฟลเดอร์โปรเจกต์

## เชื่อมกับโต๊ะบนเว็บ (เช่น โต๊ะ D18)

1. ต้องรัน [`supabase/points.sql`](../supabase/points.sql) บน Supabase ก่อน (ถ้าเคยรันแล้วให้**รันอีกรอบ** — รันซ้ำได้ปลอดภัย)
2. เว็บ → **ผู้ดูแล → อุปกรณ์เซนเซอร์** → เลือกโต๊ะที่จะวางบอร์ด (เช่น **D18**) → **เพิ่มอุปกรณ์**
3. หน้าต่าง "คีย์เชื่อมเซนเซอร์กับโต๊ะเดี่ยว D18" → กด **คัดลอกโค้ด** แล้ววาง 5 บรรทัด
   (`# เชื่อมกับ…`, `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `DEVICE_ID`, `DEVICE_KEY`) ทับของเดิมใน**ส่วนที่ 1** ของ `link_board/main.py` (**บอร์ดที่ 2**)
   **คีย์แสดงแค่ครั้งเดียว** ถ้าทำหาย กด **สร้างคีย์ใหม่**
4. เปิดบอร์ด → Shell ขึ้น `เชื่อมกับโต๊ะ D18 แล้ว` และจอมุมซ้ายบนขึ้น `D18` → บอร์ด**เฝ้าเสียงเฉพาะการจองของโต๊ะ D18**
   หน้าผู้ดูแลอุปกรณ์จะขึ้น **ออนไลน์** ภายใน 1 นาที

## เชื่อมต่อ / ตัดการเชื่อมต่อ / ย้ายโต๊ะ

ทั้งหมดกดที่เว็บ → **ผู้ดูแล → อุปกรณ์เซนเซอร์** — บอร์ดรู้เองภายใน 30 วินาที

| อยากทำ | กดอะไร | ต้องแก้โค้ดบอร์ดไหม |
|---|---|---|
| เริ่มทดสอบ (เชื่อมต่อ) | **เพิ่มอุปกรณ์** เลือกโต๊ะ แล้วเอาคีย์ไปใส่ในส่วนที่ 1 ของ `main.py` | ใส่คีย์ครั้งเดียว |
| หยุดทดสอบชั่วคราว | **ตัดการเชื่อมต่อ** — บอร์ดหยุดเฝ้าเสียง ไฟดับ ไม่หักแต้ม จอขึ้น `OFF` | ไม่ต้อง |
| กลับมาทดสอบ | **เชื่อมต่ออีกครั้ง** | ไม่ต้อง |
| ย้ายบอร์ดไปโต๊ะอื่น | **ย้ายโต๊ะ** แล้วยกบอร์ดไปวางที่โต๊ะใหม่ | ไม่ต้อง (คีย์เดิม) |
| เลิกใช้ถาวร | **ลบ** — คีย์นี้ใช้ไม่ได้อีก | — |
| คีย์หลุด/ทำหาย | **สร้างคีย์ใหม่** | ต้องใส่คีย์ใหม่ |

อยากใช้บอร์ดแบบไม่ยุ่งกับเว็บเลย (เช่นลองวงจร) → ตั้ง `TEST_MODE = True` ในส่วนที่ 1

## ทดสอบวงจรก่อน (ไม่ต้องต่อเว็บ)

ตั้ง `TEST_MODE = True` ในส่วนที่ 1 → บอร์ดจะถือว่ามีคนจองอยู่ตลอด ไม่หักคะแนนจริง
ลองพูดเสียงดังใส่ไมค์ → ครบ 5 วินาทีไฟเขียวติด → อีกรอบเหลือง → อีกรอบแดง
กด **ปุ่ม BOOT** บนบอร์ด = เริ่มรอบใหม่ — ทดสอบเสร็จอย่าลืมเปลี่ยนกลับเป็น `False`

## จับเฉพาะเสียงคนพูด

นับเสียงดังเฉพาะตอนที่**เป็นเสียงคนพูด**และดังเกิน 65 dB — เสียงอื่นถือว่าเงียบ (`VOICE_ONLY = True`)

| เช็คอะไร | ทำไม |
|---|---|
| กรองเหลือช่วงความถี่เสียงพูด 250–3400 Hz แล้ววัด dB เฉพาะช่วงนี้ | ตัดเสียงหึ่งแอร์/พัดลม/เครื่องจักร (ต่ำ) และเสียงซ่า/เสียงแหลม (สูง) |
| พลังงานเสียงต้องอยู่ในช่วงเสียงพูดอย่างน้อย 35% | เสียงหึ่งเครื่องจักรพลังงานอยู่นอกช่วง → ไม่ใช่เสียงคน |
| เสียงต้องขึ้น-ลงเป็นจังหวะพยางค์ (ย้อนหลัง 1 วิ ต่างกัน ≥ 4 dB) | คนพูดเป็นพยางค์มีช่วงเงียบสั้น ๆ คั่น — พัดลม เสียงซ่า เสียงบี๊บ ดังเท่ากันตลอด → ไม่ใช่เสียงคน |

- ตอนเป็นเสียงคนพูดดัง จอเปลี่ยนเป็นตาโกรธ และใน Shell เห็น เช่น `เสียงคน (ช่วงพูด 92%, จังหวะ 11.3 dB)`
- ข้อจำกัด: เสียงร้องเพลง/เพลงที่มีคนร้องก็เป็นเสียงคน อาจถูกนับ / เสียงเคาะรัว ๆ ที่ดังมากอาจหลุดมาได้บ้าง
- พูดดังแล้วไม่ถูกนับ → ดูค่า `จังหวะ` ใน Shell ถ้าต่ำกว่า 4 ลองลด `SPEECH_MOD_DB` เป็น 3 / อยากนับทุกเสียงเหมือนเดิม → `VOICE_ONLY = False`

## ลดเสียงรบกวน (denoise)

ค่าที่ใช้ตัดสินว่า "เสียงดัง" ผ่านการกรอง 3 ชั้น

| ชั้น | กรองอะไร | ทำยังไง |
|---|---|---|
| 1. ไมค์ | เสียงหึ่งความถี่ต่ำ + ค่า DC | INMP441 มีตัวกรองความถี่ต่ำ (~60 Hz) ในตัว + โค้ดลบค่าเฉลี่ย DC ทุก 0.03 วิ |
| 2. เสียงพื้นหลัง | แอร์ พัดลม คอม เสียงห้องปกติ | 3 วิแรกหลังเปิดเครื่องฟังระดับเสียงห้อง แล้วหักพลังงานส่วนนั้นออก — ห้องเงียบลงตามลงเร็ว, ดังขึ้นเล็กน้อยตามขึ้นช้า ๆ, แต่เสียงคนพูด (ดังกว่าพื้นหลังเกิน 6 dB) ไม่ถูกนับเป็นพื้นหลัง |
| 3. เสียงกระแทก | ของตก ปิดประตู เคาะโต๊ะ | ใช้ค่ากลาง (median) ของ 5 ช่วงล่าสุด — เสียงที่สั้นกว่า ~0.3 วิ ถูกตัดทิ้ง ไม่นับเป็นเวลาดัง |

ตัวอย่าง
- ห้องมีเสียงแอร์ 45 dB + คนคุย 70 dB → หลังกรองยังเป็น 70 dB (นับ) — เสียงคนแทบไม่ถูกลด
- ห้องมีแต่เสียงแอร์ → จอขึ้น 30 (เงียบ) ไม่นับว่าดัง
- หนังสือหล่นเสียงดัง 90 dB แป๊บเดียว → ไม่นับเป็นเวลาดัง

ปรับได้ใน `main.py` ส่วนที่ 1: `DENOISE` (ปิด = ใช้ค่าดิบ), `CALIBRATE_SECONDS`, `FLOOR_MAX_DB` (หักพื้นหลังได้สูงสุด 55 dB — กันกรณีเปิดเครื่องตอนคนกำลังคุย), `MEDIAN_WINDOWS`
ใน Shell จะเห็นทั้งค่าหลังกรองและค่าดิบ เช่น `dB 62.0 (ดิบ 62.1, พื้นหลัง 45.3)`

## หน้าจอ OLED (ตัวอักษรอังกฤษเท่านั้น จอเล็กไม่มีฟอนต์ไทย)

แถวบนสุดเสมอ: `D18 W1          42m LEFT` = โต๊ะที่เชื่อม (+ เตือนไปแล้วกี่ครั้ง) | เหลือเวลาจองกี่นาที

| สถานการณ์ | จอแสดง |
|---|---|
| เงียบ (มีการจอง) | **ตา 2 ข้างมีคิ้ว หน้าเป็นมิตร** มองไปมา กะพริบ 6 วินาที ↔ สลับกับ `QUIET FOR` **เงียบมาแล้ว** `45s` / `12m05s` / `1h02m` 4 วินาที |
| เริ่มมีเสียงพูดดัง (2 วินาทีแรก) | **ตาโกรธ** คิ้วขมวด เปลือกตาหรี่ จ้องตรงมา |
| 3 วินาทีสุดท้าย | ตัวเลข **3 → 2 → 1** ตัวใหญ่ + บรรทัดล่างบอกผล `NEXT: GREEN` / `NEXT: YELLOW` / `NEXT -5PT` (จำนวนตามระบบคะแนนบนเว็บ) |
| ครบ 5 วินาที | ไฟเตือนติด + ข้อความใหญ่ `WARN 1` / `WARN 2` / `-5 PT` แล้ว**เวลาที่เงียบเริ่มนับจาก 0** |
| หยุดพูดกลางคัน (เกิน 1.5 วินาที) | ตากลับมาเป็นมิตร (เวลาที่ดังไปแล้วยังเก็บไว้ ถ้าเงียบต่อเกิน 10 วินาทีจึงล้าง) |
| ไม่มีการจอง / ถูกตัดการเชื่อมต่อ / เพิ่งเปิดเครื่อง | ตาหลับ `z Z` + `NO BOOKING` / `DISCONNECTED` / `CALIBRATING` |

ค่า dB ดูได้ใน Shell ของ Thonny ทุก 1 วินาที

สถานะมุมขวาบน: `OFF` ผู้ดูแลตัดการเชื่อมต่อ, `TEST` โหมดทดสอบ, `NO SETUP` ยังไม่ตั้งค่า WiFi/เว็บ, `NO WIFI` ต่อ WiFi ไม่ได้, `FREE` ไม่มีการจอง

## ปรับค่า dB ให้ตรงของจริง

ค่าบนจอเป็นค่าประมาณจากความไวของไมค์ (ไม่ใช่เครื่องวัดเสียงมาตรฐาน)
เปิดแอปวัดเสียงในมือถือวางข้างไมค์ แล้วเทียบ ถ้าจออ่านต่ำกว่าแอป 4 dB → ตั้ง `DB_OFFSET = 4`

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `ImportError: no module named 'ssd1306'` | ยังไม่ได้ติดตั้งไลบรารีจอ (ขั้นตอนที่ 2 ของการติดตั้ง) |
| `ไม่เจอจอ OLED` | เช็คสาย SDA→D21, SCK→D22, VDD→ราง +, GND |
| `ไมค์ไม่ส่งเสียงมา` / dB ค้างที่ 0 | เช็ค SD→D23, WS→D19, SCK→D18 และ **L/R ต้องต่อ GND** |
| ไฟไม่ติด | กลับด้าน LED (ขายาวต้องต่อฝั่ง D-pin) / ลืมต่อขาสั้นเข้า GND |
| จอขึ้น `NO WIFI` | ESP32 ใช้ได้แค่ WiFi 2.4 GHz / เช็คชื่อ-รหัส |
| `BAD_DEVICE` | DEVICE_ID/KEY ผิด → หน้าผู้ดูแลกด **สร้างคีย์ใหม่** |
| จองแล้วแต่บอร์ดไม่เฝ้าเสียง | ดูท้ายบรรทัดใน Shell (พิมพ์ทุก 1 วินาที) บอกสาเหตุตรง ๆ: `ยังต่อ WiFi ไม่ได้ — รหัส WiFi ผิด / ไม่เจอชื่อ WiFi`, `ยังคุยกับเว็บไม่ได้ — คีย์อุปกรณ์ไม่ถูกต้อง / หาเว็บไม่เจอ / HTTPS ไม่สำเร็จ`, หรือ `เว็บยืนยันแล้ว: โต๊ะ D18 ไม่มีการจองตอนนี้` (= ที่นั่งที่ผูกอุปกรณ์ไม่ตรงกับที่จอง หรือยังไม่ถึงเวลาจอง) — จอบอร์ดขึ้น `BAD KEY` / `WEB ERR` + `SEE SHELL` |
| ค่า dB บนจอต่ำกว่าแอปในมือถือ | จอวัดเฉพาะช่วงเสียงพูด + หักเสียงพื้นหลังออก (ดูค่าดิบใน Shell) — ถ้าไม่ต้องการ ตั้ง `VOICE_ONLY = False` / `DENOISE = False` |
| พูดดังแล้วไม่ถูกนับ | Shell ขึ้น "ไม่ใช่เสียงคน" → ดูค่า `จังหวะ` ถ้าต่ำกว่า 4 ลด `SPEECH_MOD_DB` เป็น 3 |
| ครั้งที่ 4 ขึ้นไปไม่ถูกหักแต้ม (`COOLDOWN`) | รัน `points.sql` ล่าสุดอีกรอบ หรือหน้าผู้ดูแล → ตั้งค่า → ช่วงพักหลังหักแต้ม ไม่เกิน 5 วินาที |

## ทดสอบไมค์ (บอร์ดที่ 1 ไม่จับเสียงพูด)

เปิด [`tools/mic_test.py`](tools/mic_test.py) ใน Thonny ขณะเสียบบอร์ดที่ 1 → กด **Run (F5)** (ไม่ต้อง Save ลงบอร์ด ไม่ทับ main.py)

1. **ขั้นที่ 1 (4 วินาที)** พูด/เคาะใกล้ไมค์ — บอกว่ามีข้อมูลมาไหม และเสียงมาช่องไหน
   - `OK เสียงมาทางช่องที่ 1 (ซ้าย)` = สายถูก
   - `เสียงมาทางช่องที่ 2 (ขวา)` = ขา **L/R ของไมค์ต้องต่อ GND** (main.py อ่านช่องที่ 1 อย่างเดียว)
   - `ไมค์ส่งแต่ค่า 0` = เช็คสาย SD→D23 / VDD→3V3 / GND
2. **ขั้นที่ 2 (ต่อเนื่อง)** ทุก 0.5 วินาทีขึ้น เช่น
   `ทั้งหมด 70.2 dB | ช่วงพูด 68.9 dB ############ | ต่ำ 5% พูด 88% อื่น 7% | จังหวะ 9.8 dB | เสียงพูด ✓ ดังเกิน!`
   - พูดใกล้ไมค์แล้ว `พูด` ต้องสูง (มากกว่า 35%) และ `จังหวะ` ต้องเกิน 4 dB ถึงจะเป็นเสียงพูด
   - `ต่ำ` สูงเกือบตลอดแม้เงียบ = เสียงหึ่งจากแอร์/พัดลม หรือไฟเลี้ยง/สาย GND ไม่ดี
   - พูดแล้ว `ช่วงพูด` แทบไม่ขยับ = ไมค์ไม่ได้ยินจริง (สาย/ขา L/R/ไมค์เสีย)

ถ่ายภาพผลขั้นที่ 1 + ช่วงที่พูดในขั้นที่ 2 ส่งมาให้ดูได้

## HTTPS หน่วยความจำไม่พอ (`ENOMEM` / `หน่วยความจำไม่พอสำหรับ HTTPS`)

ESP32 รุ่นธรรมดา (เช่น ESP-32D / WROOM) ไม่มี RAM เสริม — การต่อเว็บแบบ HTTPS ต้องใช้หน่วยความจำฝั่งระบบก้อนใหญ่ (~40,000 ไบต์)
เฟิร์มแวร์ MicroPython รุ่นเก่าให้ Python กินหน่วยความจำไปเกือบหมด HTTPS เลยต่อไม่ได้ (โค้ดปิดไมค์ระหว่างส่งให้แล้ว แต่ถ้ายังไม่พอ ต้องอัปเดตเฟิร์มแวร์)

**อัปเดตเฟิร์มแวร์ใน Thonny** (ไฟล์บนบอร์ดจะถูกลบ ต้องใส่กลับใหม่ — เก็บ `main.py` ที่ใส่คีย์แล้วไว้ในคอมก่อน)
1. **Tools → Options… → แท็บ Interpreter** → เลือก *MicroPython (ESP32)* → กดลิงก์ **Install or update MicroPython (esptool)** มุมล่างขวา
2. Target port = พอร์ตของบอร์ด, MicroPython family = **ESP32**, variant = **Espressif • ESP32 / WROOM**, version = **รุ่นล่าสุด** → **Install**
   (ถ้าค้างที่ `Connecting...` ให้กดปุ่ม **BOOT** บนบอร์ดค้างไว้จนเริ่มเขียน)
3. เสร็จแล้วกด Close → OK → ติดตั้งไลบรารีจอใหม่: **Tools → Manage packages → ssd1306 → Install**
4. เปิด `main.py` → **File → Save as… → MicroPython device → `main.py`** → **Stop/Restart**
5. บรรทัดแรกใน Shell ต้องขึ้นเวอร์ชันใหม่ เช่น `MicroPython 1.24.1 | Python ว่าง … | ระบบว่าง … (ก้อนใหญ่สุด …)` แล้วตามด้วย `คุยกับเว็บได้แล้ว`

ถ้าอัปเดตแล้วยังไม่ได้ ถ่ายภาพ Shell ส่วนที่มี `ระบบว่าง … (ก้อนใหญ่สุด …)` และรายละเอียดหน่วยความจำ (`GC: total …`) ที่บอร์ดพิมพ์ให้ครั้งแรกที่ส่งไม่สำเร็จ

## ความปลอดภัย

- `SUPABASE_ANON_KEY` เป็นคีย์สาธารณะ (อยู่ในหน้าเว็บอยู่แล้ว) ยืนยันตัวบอร์ดด้วย `DEVICE_KEY` แทน
- เว็บเก็บ `DEVICE_KEY` แบบ hash เท่านั้น ดูย้อนหลังไม่ได้ ต้องสร้างใหม่อย่างเดียว
- อย่าอัปไฟล์ `main.py` ที่ใส่คีย์จริงแล้วขึ้น GitHub
