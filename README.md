# ระบบจองห้องสมุด (library-booking-v2)

เว็บจองโต๊ะ/ห้องประชุมในห้องสมุด — เวอร์ชันสร้างใหม่ เริ่มจากระบบสมาชิกก่อน

- **เว็บจริง:** https://sirapobsak.github.io/library-booking-v2/
- **Repo:** `sirapobsak/library-booking-v2` (push ขึ้น `main` = เว็บอัปเดตอัตโนมัติใน 1-2 นาที)
- **AI agent ที่จะมาแก้โปรเจกต์นี้ อ่าน [AGENTS.md](AGENTS.md) ก่อน**

## สถานะตอนนี้

- [x] หน้าแรก = หน้าเข้าสู่ระบบ มีแท็บสลับ **เข้าสู่ระบบ / ลงทะเบียน**
- [x] เข้าสู่ระบบ: อีเมล **หรือ** เบอร์โทรศัพท์ + รหัสผ่าน
- [x] ลงทะเบียน: ชื่อ, นามสกุล, เบอร์โทรศัพท์, อีเมล, รหัสผ่าน + ยืนยันรหัสผ่าน
- [x] เก็บข้อมูลจริงบน Supabase (ล็อกอินค้างแม้รีเฟรช)
- [x] หน้าเลือกโซน 3 โซน (E-Lecture / โซฟา / เงียบ) กดเข้าไปหน้าของแต่ละโซนได้
- [x] โซนเงียบ: ผังที่นั่งและโครงสร้างอาคารวาดตามแปลนจริง กดเลือกที่นั่งได้ (56 จุด)
- [x] โซนเงียบ: จองได้เฉพาะคนที่ล็อกอิน เลือกเวลาเริ่ม–สิ้นสุด + จำนวนคน ที่นั่งที่มีคนจองเป็นสีแดง ยกเลิกของตัวเองได้
- [x] จองหลายคน -> ได้ QR + รหัส 6 หลัก เพื่อนสแกน/กรอกรหัสที่หน้า "เข้าร่วมด้วยรหัส" ด้วยบัญชีตัวเอง (ยังไม่ล็อกอินจะพาไปล็อกอินก่อนแล้วพากลับมา)
- [x] รัน `supabase/bookings.sql` บน Supabase แล้ว — การจองเก็บในฐานข้อมูลจริง ทุกเครื่องเห็นตรงกัน
- [x] ระบบคะแนนสะสม + เซนเซอร์เสียง ESP32 — ผู้ใช้เห็นแค่คะแนน (`/points`), ผู้ดูแลจัดการคะแนน/อุปกรณ์/ตั้งค่า (`/admin`)
- [x] ระบบ 2 มิเตอร์: **ความประพฤติ** 0–100 (บันไดสิทธิ์ ปกติ/เตือน/จำกัด 1–2/ระงับ + อุทธรณ์) + **เหรียญ** แลกคูปอง
      + สถิติ "เงียบติดต่อกัน" (ไฟบนหน้าคะแนนสะสม) + ปุ่มเช็คอินที่โต๊ะ
- [x] จอทีวีในโซน (ไม่ต้องล็อกอิน): `#/tv` ตามองรอบห้อง เสียงดังที่โต๊ะไหนตาหันไป + ขอบจอแดง,
      `#/tv/stats` สถิติวันนี้ vs เมื่อวาน, `#/tv/auto` สลับ 2 หน้าเอง
- [ ] รัน `supabase/bookings.sql` แล้วตามด้วย `supabase/points.sql` **ใหม่** บน Supabase (+ ตั้งผู้ดูแลคนแรกถ้ายังไม่ได้ตั้ง)
- [ ] ผังที่นั่งของอีก 2 โซน

## วิธีรัน

```bash
npm install
npm run dev
```

ทดสอบโดยไม่ต่อ Supabase (บัญชี/การจอง/คะแนนเก็บในเบราว์เซอร์ ทุกบัญชีเป็นผู้ดูแล):

```bash
npm run dev:mock
```

เปิด http://localhost:5174/library-booking-v2/

## การตั้งค่าฐานข้อมูล

ค่า config อยู่ในไฟล์ `.env` (ไม่ขึ้น git):

```
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_xxxxx
```

ถ้าจะใช้โปรเจกต์ Supabase ใหม่ ให้เอา `supabase/schema.sql` ไปวางใน
**Supabase Dashboard → SQL Editor → Run** (รันซ้ำได้ ไม่พัง) ไฟล์นั้นสร้าง

- ตาราง `profiles` (ชื่อ/นามสกุล/เบอร์/อีเมล) + RLS ให้แต่ละคนเห็นเฉพาะของตัวเอง
- trigger สร้างแถว `profiles` อัตโนมัติเมื่อมีคนสมัคร
- ฟังก์ชัน `get_email_by_phone` ใช้ตอนล็อกอินด้วยเบอร์โทร

> รหัสผ่านไม่ได้เก็บในตารางเราเอง — Supabase Auth เก็บให้ในตาราง `auth.users`
> แบบเข้ารหัสไว้แล้ว (ปลอดภัยกว่าและเป็นวิธีที่ถูกต้อง)

### เปิดระบบจองให้ทุกคนเห็นตรงกัน

รัน `supabase/bookings.sql` ใน SQL Editor อีก 1 ครั้ง (หลัง `schema.sql`) ไฟล์นี้สร้าง

- ตาราง `seat_bookings` (1 แถว = 1 การจอง มีช่วงเวลา จำนวนคน และรหัส 6 หลักถ้าจองหลายคน) — กันจองเวลาทับกันที่ระดับฐานข้อมูล
- ตาราง `seat_booking_members` (คนที่สแกน/กรอกรหัสเข้าร่วม)
- RLS: ต้องล็อกอิน, เห็นรหัส/รายชื่อได้เฉพาะคนจองกับคนที่เข้าร่วมแล้ว, ยกเลิกได้เฉพาะคนจอง
- ฟังก์ชัน `get_zone_bookings`, `create_booking`, `get_booking_by_code`, `join_booking`

ก่อนรัน หน้าเว็บจะใช้ localStorage แทนและขึ้นแถบสีเหลืองเตือนไว้ใต้ผัง

## โหมดทดลอง (fallback)

ถ้าต่อ Supabase ไม่ได้ (เช่นโปรเจกต์แพลนฟรีถูกพักเพราะไม่ได้ใช้นาน ๆ)
แอปจะสลับไปโหมดทดลองอัตโนมัติ — สมัคร/ล็อกอินได้ปกติ แต่ข้อมูลเก็บใน
เบราว์เซอร์เครื่องนั้นเท่านั้น และจะขึ้นแถบสีเหลืองเตือนไว้บนหน้าล็อกอิน

```
src/
  main.jsx           จุดเริ่มต้น + Router + AuthProvider
  App.jsx            เส้นทางหน้า (ยังไม่ล็อกอิน -> /login)
  auth.jsx           ระบบสมาชิก: สมัคร / ล็อกอิน / ออกจากระบบ
  supabase.js        เชื่อมต่อ Supabase + เช็คว่าเซิร์ฟเวอร์ยังออนไลน์
  data.js            ข้อมูลโซน (แก้/เพิ่มโซนได้ที่ไฟล์นี้ไฟล์เดียว)
  bookings.js        ระบบจอง: จอง/ยกเลิก/รหัส 6 หลัก/เข้าร่วม (Supabase ถ้ารัน bookings.sql แล้ว ไม่งั้นใช้ localStorage)
  layouts/
    quietZone.js     พิกัดที่นั่งทุกจุดของโซนเงียบ (แก้ตำแหน่ง/จำนวนที่นี่)
    index.js         seatName(): ชื่อที่นั่งแบบอ่านง่าย ใช้ข้ามโซน
  components/
    Header.jsx       แถบบนสุด (ชื่อผู้ใช้ + ออกจากระบบ)
    QuietFloorPlan.jsx  ผังที่นั่งโซนเงียบ + กล่องจองใต้ผัง
    BookingModal.jsx ถาม "กี่โมงถึงกี่โมง" + "กี่คน" แล้วจอง
    BookingQr.jsx    QR + รหัส 6 หลัก + รายชื่อคนที่เข้าร่วมแล้ว
    Modal.jsx        หน้าต่างป๊อปอัปกลางจอ
  pages/
    AuthPage.jsx     หน้าเข้าสู่ระบบ + ลงทะเบียน (พร้อมตรวจข้อมูล)
    Zones.jsx        หน้าเลือกโซน (หน้าแรกหลังล็อกอิน)
    ZonePage.jsx     หน้าของแต่ละโซน /zone/:zoneId
    JoinPage.jsx     /join, /join/:code — เข้าร่วมโต๊ะด้วย QR/รหัส
supabase/
  schema.sql         SQL สำหรับสร้างตาราง profiles
  bookings.sql       ตารางการจอง + สมาชิกโต๊ะ + RLS + ฟังก์ชันจอง/เข้าร่วม (รันหลัง schema.sql)
```
